# TravelBot — туристичний чат-бот

Інтелектуальний туристичний консультант,
розроблений мовою Python.

## Можливості
- Розпізнавання 9 намірів користувача.
- Рекомендації туристичних напрямків.
- Інформація про пам'ятки.
- Поради щодо транспорту та проживання.
- Аналіз бюджету й тривалості подорожі.
- Збереження контексту діалогу.

## Технології
- Python
- scikit-learn
- TF-IDF
- Logistic Regression
- JSON
- Регулярні вирази

## Запуск

python -m pip install -r requirements.txt

python main.py
